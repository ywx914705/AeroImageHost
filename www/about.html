AeroImageHost

新一代高性能图片与文件托管服务。基于 C++17 + Drogon 构建，专为速度和可靠性设计。

C++17 + Drogon

高性能 HTTP 框架，单机 QPS 80K+，毫秒级响应

MySQL 8 + Redis

可靠元数据存储 + 高速缓存，多层缓存策略

MinIO 对象存储

S3 兼容，支持预签名直传，海量文件存储

libvips 图片处理

实时缩略图生成，高质量 JPEG 输出，水印支持

Vue 3 前端

现代化 SPA，Element Plus UI，暗色模式

Docker 一键部署

完整容器化，MySQL + Redis + MinIO + Nginx 全栈
