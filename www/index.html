常见问题

支持哪些文件格式？
支持 26 种格式：图片（JPG/PNG/GIF/WebP）、文档（PDF/DOC/DOCX/PPT/XLS）、视频（MP4/WebM/MOV）、音频（MP3/WAV/FLAC）以及压缩包（ZIP/RAR/7Z）等。
单个文件大小限制是多少？
默认 100MB，可配置至 10GB。大文件自动分片上传，每片 20MB，确保传输稳定。
上传中途断网了怎么办？
支持断点续传。重新上传同一文件会自动跳过已完成的分片，从断点继续，无需重新开始。
我的文件安全吗？谁能看到？
默认私有，只有您自己可以查看。Token 鉴权 + Redis 会话管理。可随时切换为公开分享。私有化部署意味着数据完全在你自己的服务器上。
分享链接会过期吗？
不会。分享链接永久有效，只要服务器正常运行就一直可用。您可以随时撤销分享权限。
免费吗？有什么限制？
注册即可免费使用全部功能，无隐藏收费、无容量限制。私有化部署方案让您完全掌控成本。
如何私有化部署？
只需 Docker 一键部署。克隆项目、配置数据库和 MinIO、执行 docker compose up 即可。详细文档可在 GitHub 获取。

AeroImageHost 是什么？

AeroImageHost 是一个高性能的文件托管与图床平台，支持图片、文档、视频、音频等 26 种文件格式的上传、管理和在线预览。它不仅仅是一个图床，更是一个完整的文件管理中枢。

支持 26 种文件格式，图片/文档/视频/音频全覆盖
大文件自动分片上传，断网续传不丢失
智能缩略图、PDF 全屏、视频在线播放
永久分享链接，支持域名白名单防盗链
私有化部署，数据完全自主可控

技术亮点

高性能

C++ 后端，接口响应 < 10ms，内存占用 80~120MB

多层缓存

Redis 缓存 + MinIO 存储，缩略图按需生成并永久缓存

安全可靠

PBKDF2 加密、Token 鉴权、暴力破解防护、请求追踪

运维友好

Docker 一键部署、内置监控面板、自动清理、优雅停机

为什么做这个项目？

市面上的图床服务要么收费昂贵，要么随时可能关停导致图片失效。AeroImageHost 的目标是提供一个完全自主可控的文件托管方案——数据在你自己的服务器上，永远不过期，永远可用。
