# AeroImageHost · 功能介绍

AeroImageHost 是一个高性能图片与文件托管平台，面向个人用户和团队，提供文件上传、管理、分享和社区发现功能。

---

## 核心功能

### 1. 文件上传

- **多种上传方式**: 拖拽上传、点击选择、粘贴上传 (Ctrl+V)
- **大文件支持**: 最大 100MB，自动分片断点续传
- **多格式支持**: 图片 (JPG/PNG/GIF/WebP/SVG)、文档 (PDF/DOC/DOCX/PPT/XLS)、视频 (MP4/WebM/MOV)、音频 (MP3/WAV/FLAC)、压缩包 (ZIP/RAR/7Z)
- **上传队列**: 实时显示上传进度、速度、剩余时间
- **上传失败重试**: 自动重试 + 手动重试

### 2. 文件管理

- **文件列表**: 卡片视图 (图片显示缩略图) + 列表视图 (紧凑信息密度)
- **分类筛选**: 按类型筛选 — 全部 / 图片 / 文档 / 视频 / 音频
- **搜索**: 文件名模糊搜索
- **排序**: 按上传时间 / 文件大小 / 文件名排序，支持升降序
- **批量操作**: 全选 / 批量删除
- **文件详情**: 点击查看完整元数据 (文件名、大小、类型、尺寸、上传时间、浏览次数)

### 3. 分享与外链

- **一键复制链接**: 复制文件的永久访问链接
- **Markdown 外链**: 复制 `![文件名](链接)` 格式，直接嵌入博客/文档
- **公开/私有切换**: 每个文件可独立设置公开或私有
- **预签名链接**: 生成带时效的安全下载链接
- **缩略图**: 通过 `?size=N` 参数动态生成指定尺寸的缩略图

### 4. 图片处理

- **智能缩略图**: 按需生成 100-2000px 任意尺寸，自动缓存
- **图片水印**: 自定义文字水印，可调位置 (9 宫格) 和透明度
- **高质量输出**: JPEG 质量 85%，保持图片清晰度

### 5. 图床大厅 (社区)

- **发布到大厅**: 用户可将自己的公开图片发布到社区广场
- **瀑布流浏览**: 瀑布流布局展示所有用户发布的图片
- **分类筛选**: 按标签分类浏览 (风景/城市/抽象/科技/美食等)
- **点赞互动**: 用户可点赞喜欢的图片
- **标签系统**: 每张图片可添加多个标签，支持标签筛选
- **排序**: 按最新 / 最热门 / 浏览量排序

### 6. 存储与统计

- **存储统计**: 实时显示文件总数、图片数量、存储空间使用量
- **类型统计**: 分别统计图片、文档、视频、音频的数量
- **使用量可视化**: 进度条展示存储占用比例

### 7. 系统功能

- **深色模式**: 一键切换亮色/暗色主题
- **响应式设计**: 适配桌面、平板、手机
- **实时健康检查**: 监控 MySQL/Redis/MinIO 连接状态
- **性能指标**: QPS、延迟分布、缓存命中率、连接池状态
- **安全限流**: 登录暴力破解防护、API 限流

- 分类标签筛选 + 发布按钮

## 文件类型识别

| 类型 | 扩展名 | 图标颜色 | 说明 |
|------|--------|---------|------|
| 图片 | jpg/png/gif/webp/svg | 蓝色 | 显示缩略图 |
| PDF | pdf | 红色 | 支持在线预览 |
| Word | doc/docx | 天蓝 | - |
| Excel | xls/xlsx | 绿色 | - |
| PPT | ppt/pptx | 橙色 | - |
| 视频 | mp4/mov/webm/avi | 紫色 | 支持在线播放 |
| 音频 | mp3/wav/flac/m4a | 粉色 | 支持在线播放 |
| 压缩包 | zip/rar/7z | 灰色 | - |
| 文本 | txt/md | 浅灰 | 支持在线预览 |

## 操作按钮说明

每个文件提供 4 个快捷操作:

1. **链接** — 复制分享链接到剪贴板
2. **MD** — 复制 Markdown 格式外链
3. **公开/私有** — 切换文件可见性
4. **删除** — 删除文件 (二次确认)
